# 节日送礼｜给家人选设备，先了解这三件事

对方平时在哪里使用、最常用来做什么、自己能不能轻松设置和操作？先弄清这几件事，再看设备类型和预算，选择会更贴近需要。

如果涉及具体活动或权益，记得以店内实际公布的信息为准；选设备本身，可以先从对方的使用习惯开始。

把家人的使用情况私信给我，我们一起缩小选择范围。
