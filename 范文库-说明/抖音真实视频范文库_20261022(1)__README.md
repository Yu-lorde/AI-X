# 抖音真实视频范文库（复赛素材）

本目录是从抖音站内真实视频整理的口播脚本范文，供模型学习营销软文的**结构与节奏**，不用于对外发布。

## 一、目录结构

```
抖音短视频范文库/
├── 范文/                      # 21 篇单篇范文（每篇一个 .md）
├── 抖音真实视频库_结构拆解.md    # 结构拆解与逐条证据说明
├── 抖音真实视频库_清单.md        # 检索到的全部真实视频清单
└── README.md                  # 本文件
```

## 二、单篇范文说明

每个 `.md` 包含：

| 部分 | 内容 | 用途 |
|------|------|------|
| front-matter | `perspective`（视角）、`product`（产品）、`audience`（人群）、`scene`（场景）、`tags`、`good_points`（可学习点） | 检索与筛选 |
| 标题信息 | 视频标题、时长/点赞 | 判断视频形态 |
| `## 口播原文` | 带 `[MM:SS]` 时间戳的逐字稿，保留原语序，仅校正同音错字 | 学习口语节奏与句式 |
| `## 结构拆解` | 开场钩子 / 中段证据 / 收尾 CTA | 学习三段式结构 |
| `## 不可迁移项` | 价格、参数、绝对化表述等不能照搬的部分 | 防止写入不实信息 |

## 四、给模型的使用规则

1. 只学结构与节奏（钩子位置、证据密度、收口方式），**不照抄原句**。
2. 参数、价格、活动规则一律以官方规格页与知识库为准；本库中的数字均为发布时的时效信息。
3. `不可迁移项` 中列出的表述（最轻、立省四位数、效率翻倍、久看不伤眼等）禁止出现在成稿中。
4. 涉及具体型号时，须与当前在售 SKU 对齐，不写已停产或未发布的配置。

## 五、采集与转写说明

- 来源：抖音站内真实视频，逐条人工挑选（时长 30–120 秒为主、有真人口播、开头 3 秒有钩子）。
- 转写：本地离线语音识别（faster-whisper medium，CPU），保留时间戳，仅校正同音错字，未润色、未改写；无有效人声的视频不入库。
- 未使用其他平台内容，未使用仿写文本，未调用第三方接口。
