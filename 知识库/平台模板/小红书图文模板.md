# 小红书图文创作指南

## 一、合规红线

不得以第一人称虚构购买、使用或测评经历。禁止出现“我入手了”“我买了”“我用了 X 个月”“亲测”“实测”“作为一名学生”等表述。用第三人称、场景视角或“如果你是……”的方式组织内容，所有结论必须来自知识库中的产品资料。

改写示例：
- “大学生活效率翻倍！我的 MateBook D 14 使用体验” → “新生选笔记本，这 3 件事先想清楚”
- “作为一名大二学生，最近入手了 HUAWEI MateBook D 14，分享一下我的使用体验” → “每天在教室、图书馆和宿舍之间来回，背包里的东西越轻越好。选本之前，先看看这几个问题。”

## 三、写作流程

首图只给一个结果或冲突；第二张交代人物和任务；中段每张解决一个问题；倒数第二张展示结果或前后对比；末图给核对清单和评论问题。正文与图序一致。

每个段落都要能回答下列至少一项：用户遇到什么问题、进行了什么动作、用什么证据验证、在哪些条件下成立、下一步做什么。不能回答这些问题的形容词、口号和重复参数应删除。


## 四、成稿格式与图文节奏

6—10张图，正文300—800字。标题避免堆叠感叹号和空泛形容词。每张图片输出文件名、来源、插入位置、图上短句和图注；参数放角标而非覆盖画面。

统一输出顺序：标题备选3个 → 受众与场景 → 正文/脚本 → 图片或镜头清单 → 事实来源 → 风险与待确认项 → CTA → 发布前检查。引用ima图片时不得只写“配一张电脑图”，必须指定图片名、来源、位置和用途。


## 九、交付字段

最终交付应包含：`platform`、`audience`、`scene`、`target`、`model_and_sku`、`system_version`、`title_options`、`body_or_script`、`image_or_shot_list`、`evidence`、`limitations`、`cta`、`verified_at`。无法确认的字段写“待人工确认”，不能删除。
